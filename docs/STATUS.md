# สถานะโปรเจกต์น้องโชคช่วย

อัปเดตล่าสุด 2026-11-23

## ตอนนี้

- น้องโชคช่วยมีคลัง OCR ภาษาไทยและค้นหา SQLite, ถาดรอตรวจ, สมุดเบิกจ่าย, แฟ้มเด็กและป้ายแพ้อาหาร รวมถึง LINE OA และตัวจำลองบนเว็บ ดูโมดูลและช่องทางนำเข้าใน [INDEX.md](../INDEX.md)
- ระบบจริงใช้ Google OAuth และจำกัดบัญชี LINE ที่เข้าถึงได้ ส่วน Vault บน Cloudflare เก็บ SQLite snapshot กับไฟล์ต้นฉบับใน R2 ส่วนตัว ตาม [ADR 0003](adr/0003-cloudflare-r2-sqlite-persistence.md) โค้ดปัจจุบันรองรับ schema 4 ซึ่งรวมค่าตั้งต้นคุณครู
- รุ่น Rich Menu ล่าสุดที่มีบันทึกการส่งงานคือ [PR #11](https://github.com/chokky-education/nong-chokchuay-ocr/pull/11) ที่ `6b9b5eb` หลัง deploy ตรวจว่าเบราว์เซอร์ได้ URL ไฟล์ตาม hash และเปิดเอกสารจากหน้าตั้งค่าได้ LINE API อ่านเมนู 8 ปุ่มกลับได้หลังติดตั้ง ดู [ผลตรวจในเครื่องก่อน release](qa/2026-11-15-rich-menu-settings.md) และ [คู่มือ Rich Menu และ rollback](rich-menu.md)

## งานค้างและข้อจำกัด

- Rich Menu ยังต้องตรวจบนแอป LINE มือถือจริง โดยเฉพาะถ่ายรูป/เลือกอัลบั้มและเปิดเว็บ รวมถึง Google sign-in ใหม่ ผลจากตัวจำลองและ LINE API ครอบคลุมคนละส่วนกับการกดในแอป
- เคยพบ HTTP 503 ระหว่างทดสอบหลัง Container หลับ 3 นาที ตัวจำลองบางคำสั่งทำงานได้หลังลองซ้ำ ส่วนรายการบิลยังมีรอบที่โหลดไม่สำเร็จ การตรวจ R2 บนระบบจริงรอบถัดไปควรครอบคลุมอัปโหลด ยืนยันบิล Watch Folder และการกู้ snapshot รุ่นก่อนตามขอบเขตที่เจ้าของอนุมัติ
- รอบตั้งค่า workflow ใช้ CI เดิมสำหรับ PR และ `main` การ deploy ผ่าน Actions จะรอให้เจ้าของกด **Run workflow** จาก `main` และกรอก SHA ที่อนุมัติ การใช้ Actions เพื่อ deploy ต้องมี `CLOUDFLARE_API_TOKEN` ดู [ขั้นตอนส่งงาน](release-workflow.md)
